# Интернет-магазин

Node.js + Express + SQLite. Каталог товаров, корзина, оформление заказа, тестовая
оплата (со структурой под ЮKassa), фото/видео галерея, админ-панель.

## 1. Установите Node.js

На этом компьютере Node.js не найден. Установите Node.js LTS одним из способов:

- скачайте установщик с https://nodejs.org (кнопка LTS) и запустите его; либо
- выполните в PowerShell:
  ```powershell
  winget install OpenJS.NodeJS.LTS
  ```

После установки откройте новый терминал и проверьте:

```bash
node -v
npm -v
```

## 2. Откройте проект в VS Code

Откройте папку `site` в VS Code (File → Open Folder) и откройте встроенный терминал
(Terminal → New Terminal).

## 3. Установите зависимости

```bash
npm install
```

> Проект использует встроенный в Node.js модуль `node:sqlite` — компилятор и
> Python для базы данных не нужны. Требуется Node.js версии 22.5 или новее.

## 4. Настройте переменные окружения

Скопируйте `.env.example` в `.env` и при желании поменяйте значения (логин/пароль
администратора, название магазина, секрет сессии):

```bash
copy .env.example .env
```

## 5. Создайте базу данных и тестовые данные

```bash
npm run db:seed
```

Это создаст файл `data/shop.db`, учётную запись администратора (логин/пароль из
`.env`) и несколько тестовых товаров.

## 6. Запустите сайт

```bash
npm run dev
```

Откройте в браузере:

- сайт — http://localhost:3000
- админка — http://localhost:3000/admin/login (логин/пароль из `.env`,
  по умолчанию `admin` / `change-me` — обязательно смените их в `.env`)

## Что уже работает

- Каталог товаров с категориями (`/catalog`)
- Карточка товара, добавление в корзину
- Корзина и оформление заказа (`/cart`, `/checkout`)
- Приём оплаты — тестовый режим (страница «Тестовая оплата»), пока не заданы ключи
  ЮKassa
- Фото/видео галерея (`/gallery`)
- Админка (`/admin`): товары (CRUD + категории на лету), заказы и их статусы,
  галерея (загрузка файлов), настройки (соцсети, контакты, название магазина)

## Подключение реальной оплаты (ЮKassa)

1. Зарегистрируйтесь и получите `shopId` и секретный ключ в личном кабинете
   ЮKassa: https://yookassa.ru/
2. Впишите их в `.env`:
   ```
   YOOKASSA_SHOP_ID=...
   YOOKASSA_SECRET_KEY=...
   ```
3. Перезапустите сервер — при оформлении заказа сайт начнёт создавать реальные
   платежи через API ЮKassa вместо тестовой заглушки (код в
   `src/services/payments/yookassa.js`).
4. Для получения уведомлений об оплате настройте в личном кабинете ЮKassa вебхук
   на адрес `https://ваш-домен/checkout/webhook/yookassa` (локально это не
   сработает без публичного адреса — для теста используйте, например, ngrok, или
   на первом этапе полагайтесь на `return_url` после оплаты).

## Структура проекта

```
src/
  server.js        # точка входа
  db/               # подключение SQLite, схема, сид тестовых данных
  middleware/        # авторизация админа, загрузка файлов (multer)
  routes/              # маршруты сайта и админки
  services/payments/    # интеграция с ЮKassa (заглушка + реальный вызов API)
  views/                # EJS-шаблоны
public/
  css/, js/, uploads/   # статика и загруженные файлы
data/
  shop.db               # файл базы данных SQLite (создаётся автоматически)
```
