Ведём личную смету расходов (не привязана строго к бизнесу/проекту) — фиксируем траты, которые упоминаются в любых чатах. Отдельно — план по расходам на рекламу (приоритет).

**Why:** Пользователь попросил (2026-08-21) вести смету "для себя" в режиме мониторинга по всем чатам, уточнять при необходимости. Уточнено: это личные расходы, не проектные/бизнес. Также (2026-08-21): эта смета в дальнейшем будет перекликаться с отчётом для брендов — прямые рекламные кампании с брендами тоже нужно учитывать здесь.
**How to apply:** Когда в разговоре всплывает трата — фиксировать: дату, статью, сумму, валюту, статус (оплачено/план). Если сумма не названа явно — уточнить у пользователя, а не додумывать. Рекламные кампании, которые оплачивает бренд-партнёр (co-marketing/спонсорство), тоже заносить отдельной строкой — пригодится для будущего отчёта для брендов ([[project_site_lev_keiser]] — там про brands-фичу и партнёрства).
