# Стикеры и эмодзи для Telegram

Готовые файлы (08.09.2026): `stickers/` — 512×512 PNG для стикерпака, `emoji/` — 100×100 PNG
для набора кастомных эмодзи. Исключены «плёнка» и «тираж»: этих тезисов у нас больше нет.

## Как загрузить (делает владелец аккаунта, у бота нет доступа к @Stickers)

1. Открыть @Stickers → /newpack → имя набора «Лев Кейсер · DJ Levka».
2. Отправлять файлы из `stickers/` по одному как документ (не как фото), после каждого — эмодзи-ассоциацию.
3. /publish → короткое имя `levkeiser` → ссылка вида t.me/addstickers/levkeiser.
4. Для эмодзи: /newemojipack, те же шаги с файлами из `emoji/`. Кастомные эмодзи в канале
   видны всем, ставить их в посты может только Premium-аккаунт.
5. Ссылку на набор — в описание канала третьей строкой после levkeiser.com и в закреп.
