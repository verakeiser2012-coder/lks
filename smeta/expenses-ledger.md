# Смета — личные расходы и рекламный бюджет

> Экспортировано из памяти сессии Claude 2026-08-21, чтобы данные были доступны из другого аккаунта. Оригинал: `project_expenses_ledger` в памяти Claude Code.

Ведём личную смету расходов (не привязана строго к бизнесу/проекту) — фиксируем траты, которые упоминаются в любых чатах. Отдельно — план по расходам на рекламу (приоритет) и раздел для бренд-кампаний (co-marketing), который в дальнейшем пригодится для отчёта брендам.

**Формат**: когда всплывает трата — дата, статья, сумма, валюта, статус (оплачено/план). Если сумма не названа явно — уточнять, а не додумывать. Рекламные кампании, которые оплачивает бренд-партнёр, заносятся отдельной строкой в раздел "Бренд-кампании".
