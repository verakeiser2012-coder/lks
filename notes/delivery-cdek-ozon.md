# Доставка: СДЭК + Ozon Доставка

Решение 11.09.2026: подключаем обе службы сразу. СДЭК — курьер до двери и ПВЗ,
Ozon Доставка — выдача в ПВЗ Ozon (дешевле: 30 ₽ за товар фиксированно с 04.06.2026).
Покупатель выбирает при оформлении, сайт считает стоимость по API обеих.

## Что делает пользователь (регистрации — только из браузера, оба сайта режут запросы с сервера)

### СДЭК
1. cdek.ru → «Для бизнеса» → регистрация как ИП, реквизиты.
2. Подписать договор-оферту в кабинете (онлайн, без визита, без минимального объёма).
3. Кабинет → Интеграция → API: получить **Account** и **Secure password**
   (это ключи API v2, не логин от кабинета).
4. Прислать оба ключа — впишу в `.env` на сервере.

### Ozon Доставка для бизнеса — подключено 13.09.2026
Два продукта у Ozon: «на продавцов» (Seller API, карточки и остатки на Ozon —
не наш случай) и **«для бизнеса»** (Ozon Delivery API, любые товары с сайта).
Кабинет доставки заведён отдельно от кабинета продавца (ID 9136965, продавец —
5868796), договор страхования подписан 13.09.

**Ключи — частное приложение кабинета доставки**, не Seller API:
Настройки → Управление частными приложениями → Создать. У нашего приложения
одобрен scope `delivery-api.all`; отдельные scope (`delivery-api.delivery`
и т. д.) отвечают «not approved», поэтому токен запрашивается с `all`.
Токен: POST https://xapi.ozon.ru/oauth/token (JSON: client_id — UUID,
client_secret, grant_type=client_credentials, scope=[…]). Рабочая среда:
https://api-delivery.ozon.ru. Серверы за testcookie: 302/307 + Set-Cookie,
повторить с кукой — обработано в src/services/delivery/ozon.js.
Проверено с VPS: `/v1/delivery/check-client` → 200, список ПВЗ отдаётся.

В .env (сервер и локально, не в git): OZON_DELIVERY_CLIENT_ID,
OZON_DELIVERY_CLIENT_SECRET, OZON_DELIVERY_METHOD_ID (пока пусто).
Seller API ключи кабинета продавца (OZON_SELLER_*) для доставки бесполезны —
удалить в кабинете, они светились в чате.

**Осталось:** завести метод доставки — кабинет доставки → «Методы доставки» →
«Создать метод доставки» (откуда отгружаем: Екатеринбург, сдача в ПВЗ Ozon);
номер под штрихкодом = shipment_method_id → OZON_DELIVERY_METHOD_ID. Без него
работают проверка покупателя и ПВЗ, но не расчёт стоимости и заказы.

Особенность Ozon: без телефона получателя стоимость не считается — телефон в
оформлении заказа у нас обязателен и так.

## Что делаю я после ключей
- расчёт стоимости и сроков на странице оформления по обеим службам;
- выбор ПВЗ (СДЭК — виджет карты, Ozon — список точек по городу);
- создание отправления после оплаты и трек-номер покупателю письмом;
- статусы в админке заказа.

Каркасы сервисов: `src/services/delivery/cdek.js`, `src/services/delivery/ozon.js` —
без ключей возвращают «недоступно», сайт продолжает работать по-старому
(адрес и ПВЗ вводятся текстом, стоимость согласуется после заказа).

## Про тарифы
Ozon: 30 ₽ за товар за выдачу в ПВЗ — новый тариф, до июня было 5–10 % (максимум 250 ₽).
Wildberries при запуске своей доставки ставки потом поднимал; если Ozon сделает так же,
СДЭК остаётся основой, а Ozon выключается одной переменной в `.env`.
