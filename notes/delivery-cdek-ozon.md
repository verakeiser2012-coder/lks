# Доставка: СДЭК + Ozon Доставка

Решение 11.09.2026: подключаем обе службы сразу. СДЭК — курьер до двери и ПВЗ,
Ozon Доставка — выдача в ПВЗ Ozon (дешевле: 30 ₽ за товар фиксированно с 04.06.2026).
Покупатель выбирает при оформлении, сайт считает стоимость по API обеих.

## Что делает пользователь (регистрации — только из браузера, оба сайта режут запросы с сервера)

### СДЭК
1. cdek.ru → «Для бизнеса» → регистрация как ИП, реквизиты.
2. Подписать договор-оферту в кабинете (онлайн, без визита, без минимального объёма).
3. Кабинет → Интеграция → API: получить **Account** и **Secure password**
   (это ключи API v2, не логин от кабинета).
4. Прислать оба ключа — впишу в `.env` на сервере.

### Ozon Доставка для бизнеса (уточнено 13.09.2026)
У Ozon два продукта. «Ozon Доставка на продавцов» (приложение в кабинете
seller.ozon.ru) требует карточки товаров и остатки на Ozon — не наш случай.
Нам нужна **«Ozon Доставка для бизнеса»**: без карточек, любые товары с сайта.

1. Кабинет продавца уже есть (ИП Кейсер, Client-Id 5868796). В нём:
   Настройки → **Кабинет доставки** → «Создать новый кабинет» (отдельный баланс
   и документы) или «Объединить кабинеты». Реквизиты подтянутся по ИНН,
   проверка ~15 минут; оферта принимается автоматически первым действием.
2. Настройки → **Договоры** → «Заключить договор страхования» — паспортные
   данные вводит пользователь. Без договора заказы не создаются.
3. **Методы доставки** → создать метод (отгрузка из Екатеринбурга через ПВЗ);
   номер под штрихкодом — ID метода.
4. Настройки → **Seller API** → «Сгенерировать ключ» — при генерации отметить
   роль Ozon Доставки/логистики (иначе методы v1/delivery/*, v2/delivery/checkout
   отвечают 403 «method is not allowed» — так было с ключом от 13.09, у которого
   роль доставки не отмечена). Работает пара заголовков Client-Id + Api-Key,
   OAuth-приложение не нужно.

Ключи лежат в .env на сервере: OZON_SELLER_CLIENT_ID, OZON_SELLER_API_KEY
(в git не попадают). Ключ из чата 13.09 после настройки перевыпустить.

Особенность Ozon: без телефона получателя стоимость не считается — телефон в
оформлении заказа у нас обязателен и так.

## Что делаю я после ключей
- расчёт стоимости и сроков на странице оформления по обеим службам;
- выбор ПВЗ (СДЭК — виджет карты, Ozon — список точек по городу);
- создание отправления после оплаты и трек-номер покупателю письмом;
- статусы в админке заказа.

Каркасы сервисов: `src/services/delivery/cdek.js`, `src/services/delivery/ozon.js` —
без ключей возвращают «недоступно», сайт продолжает работать по-старому
(адрес и ПВЗ вводятся текстом, стоимость согласуется после заказа).

## Про тарифы
Ozon: 30 ₽ за товар за выдачу в ПВЗ — новый тариф, до июня было 5–10 % (максимум 250 ₽).
Wildberries при запуске своей доставки ставки потом поднимал; если Ozon сделает так же,
СДЭК остаётся основой, а Ozon выключается одной переменной в `.env`.
