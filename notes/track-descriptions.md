# Описания треков DJ Levka (канон)

Единый источник текстов для сайта (таблица `tracks.description`), IPEX, дистрибьюторов и площадок.
Обновлено 13.09.2026: тексты на сайте и на IPEX совпадают. Менять здесь и в обоих местах.

| Трек | Релиз | Описание |
|---|---|---|
| Ikigai | Ikigai (EP, 2024) | Заглавный трек дебютного EP — про поиск своего смысла. Стиль: lofi hip-hop. |
| The Sleepiest Beatmaker | Ikigai | Ироничная самопрезентация — сонный битмейкер за работой. Стиль: chillhop. |
| Cozy Place | Ikigai | Один из самых атмосферных треков EP Ikigai: тёплое, укрытое место. Стиль: ambient lofi. |
| Fog | Ikigai | Туманное, приглушённое звучание — как взгляд сквозь дымку. Стиль: downtempo. |
| Bill Cipher | Ikigai | Название-отсылка к культовому персонажу — трек с лёгким налётом мистики. Стиль: dark lofi hip-hop. |
| BERSERK | сингл, 2024 | Минута сорок семь без единой лишней детали: барабаны на пределе, синт держит одну ноту и не отпускает. Самый быстрый и злой трек в каталоге. Стиль: hard techno. |
| Welcome | сингл, 2024 | Первый трек, с которого начинается знакомство: короткое вступление, приглашающий синт и тёплый бас. Стиль: chillwave. |
| Game Over | сингл, 2024 | Совместный трек с openedruf: игровые синты и бит с восьмибитным привкусом. Стиль: chiptune / lo-fi. |
| Deep Sleep | сингл, 2024 | Музыка для той стадии сна, где ещё слышно комнату. Медленный пульс, приглушённые клавиши, ни одного резкого звука. Стиль: ambient, downtempo. |
| At The Jazz Club | сингл, 2024 | Живые барабаны, контрабас и пыльный рояль, записанные так, будто это старая плёнка из клуба. Стиль: jazzy lo-fi. |
| Hotline | сингл, 2024 | Ночной звонок из восьмидесятых, на который никто не берёт трубку. Стиль: synthwave / chillwave, 90 BPM. |
| Spooky Month | сингл, 2024 | Хэллоуинский бит с органом и скрипучими семплами: жутковато, но уютно. Стиль: lo-fi / dark chill. |
| Mystery Shack | не издан | Загадочный бит с расстроенными клавишами: та же вселенная, что у Bill Cipher, только снаружи. Стиль: lo-fi. |
| Ruins | не издан | Гулкое пространство, редкие удары и эхо — трек, в котором больше воздуха, чем нот. Стиль: ambient. |
| Flowers | Flowers (EP, 2025) | Заглавный трек — хрупкое, цветущее начало альбома о чувствах. Стиль: dream pop / lofi. |
| Memory | Flowers | Трек-воспоминание: тёплая грусть по тому, что уже не вернуть. Стиль: ambient lofi. |
| U | Flowers | Самый личный трек альбома — обращение к одному человеку. Стиль: bedroom pop. |
| Riff Raff | Flowers | Более дерзкий, шершавый по звучанию момент альбома. Стиль: lofi hip-hop. |
| Lullaby | Flowers | Колыбельная в конце пути — мягкое закрытие альбома. Стиль: ambient / downtempo. |
| Bubblegum | сингл, 2025 | Приторно-яркий бит с игрушечными синтами: три минуты, в которых ничего не происходит всерьёз. Стиль: hyperpop, bubblegum bass. |
| Glitch | сингл, 2026 | Трек, собранный из сбоев: обрывки сэмплов, срезанные хвосты, ритм, который спотыкается нарочно. Стиль: glitch, IDM. |
| Soundstates | Soundstates (EP, 2026) | Заглавный трек альбома — фирменное звучание DJ Levka: ретро-синты и lo-fi атмосфера. Стиль: synthwave. |
| d r e a m | Soundstates | Плывущий, полусонный трек — как обрывок сна, который пытаешься удержать. Стиль: vaporwave. |
| Back to the Future | Soundstates | Ретрофутуризм в звуке: synthwave-ностальгия по будущему, каким его видели из прошлого. Стиль: retrowave. |
| 2AM | Soundstates | Час ночи, когда город затихает — трек для одиноких прогулок под неон. Стиль: lofi house. |
| Cloudflute | Soundstates | Воздушная, почти невесомая мелодия — звук, будто сыгранный на облаке. Стиль: jazzy lofi. |
