Состояние на 01.09.2026.

## Что уже сделано

Условия Spotify Developer Terms приняты пользователем, приложение создано в дашборде
`developer.spotify.com/dashboard`.

| Параметр | Значение |
|---|---|
| Название | DJ Levka Analytics |
| Client ID | `da477e74da2c41c3baf9b80b432a52c5` |
| Статус | Development mode |
| Redirect URI | `http://127.0.0.1:3000/callback` |
| Сайт | levkeiser.com |
| API | Web API |

**Client secret намеренно не сохранён** ни здесь, ни где-либо ещё: пока API заблокирован, он
бесполезен, а держать его в репозитории неправильно. Возьмём из дашборда, когда дойдём до
подключения — там кнопка «View client secret».

## Чего не хватает

На странице приложения висит:

> «Your application is blocked from accessing the Web API since you do not have a Spotify Premium
> subscription. Upgrade to Spotify Premium to access the Web API and unlock additional features
> for your app.»

То есть **Spotify требует активную подписку Premium** на аккаунте, под которым создано приложение.
Раньше Web API был открыт всем, теперь нет — это часть изменений, о которых у них висит баннер
«Update on Developer Access and Platform Security».

Пользователь сообщила 01.09.2026, что вариант оплатить Premium есть и она это сделает позже.
После оплаты приложение заработает без каких-либо дополнительных действий — ключи уже выпущены.

## Что делаем, когда Premium появится

Задача: **страница в админке сайта, которая сама показывает Popularity Score по всем 24 трекам**
и его динамику. Сейчас это число видно только в интерфейсе SubmitHub, по одному треку за раз,
вручную — а оно у нас главный измеритель успеха продвижения.

Как устроено технически:

1. **Client Credentials flow** — самый простой: POST на `accounts.spotify.com/api/token` с client id
   и secret, в ответ токен на час. Права на аккаунт слушателя не нужны, читаем только публичные
   данные.
2. Запрос `GET /v1/tracks?ids=...` — до 50 треков за раз, в ответ поле `popularity` (0–100)
   по каждому. Наши 24 трека влезают одним запросом.
3. `GET /v1/artists/2Yk65GNoUclS0VKtyvCebY` — там же `popularity` и `followers` артиста.
4. Складывать замеры в таблицу с датой, рисовать динамику. Раз в сутки достаточно.

Spotify ID треков придётся собрать один раз — они выводятся из album ID, которые у нас есть
в `notes/sundesire-audit.md`.

**Зачем это нужно именно нам:** мы отправляем 43 кредита на кампанию по Soundstates и хотим
понять, сработала ли она. Без автоматического замера мы узнаем это только когда кто-то вручную
откроет SubmitHub — то есть, скорее всего, поздно и не полностью.

## Заодно: список того, что разблокирует иностранная карта

Задач набралось пять, и это уже не мелочь:

1. **Spotify Premium** — Web API и трекер Popularity Score
2. **Printful** — печать по требованию для зарубежных заказов
3. **SubmitHub** — пополнение кредитов, когда закончатся нынешние 78
4. **Meta Ads** — платная реклама на международную аудиторию
5. **Feature.fm** — пре-сейвы к релизу Hotline

Одно действие, пять направлений. По приоритету это теперь самая окупаемая задача из всех
«только ты».
